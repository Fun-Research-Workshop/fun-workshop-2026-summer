Workshop Syllabus

课程安排

This syllabus is designed as a zero-to-one workshop path for beginners. It starts with setup and model basics, then moves toward customization, agent patterns, and practical projects.

这门工坊面向零基础参与者设计，从环境搭建和大模型基础出发，逐步走向定制化、Agent 设计模式与实践应用。

🧭 Zero-to-One Workshop Path

🧭 零基础课程路径

The remaining modules turn the basics into a usable assistant. Each session follows a concept-demo-practice rhythm so participants can keep moving forward even if they start from scratch.

后续课程会把基础能力逐步转成可用的助手。每一课都遵循“概念讲解 - 演示 - 动手练习”的节奏，让零基础同学也能跟上。

Customization & Training: Make the Claw Fit You 定制化训练：让 Claw 贴合你的习惯
Learn how to adjust system prompts, memory, tool preferences, and response style so the assistant reflects your own workflow and habits. Each participant leaves with a personalized starter profile.
学习如何调整系统 Prompt、记忆、工具偏好和回复风格，让助手真正贴合你的使用习惯。每位同学都会带走一个可继续迭代的个性化初始配置。

Common Agent Design Patterns Agent 常见设计模式
Learn the most useful patterns for beginners: planner-executor, tool calling, reflection, memory, and human-in-the-loop approvals. We will walk through one pattern and wire it into a small agent flow.
学习最实用的入门模式：规划-执行、工具调用、反思、记忆与人类审批。我们会带着大家把其中一种模式接到一个小型 Agent 流程里。
Session 5 第 5 课 TBC 待定
Practical Applications & Mini Project 实践应用与迷你项目
Turn the workshop into something useful: choose a scenario such as calendar help, note-taking, study support, or task reminders, then finish a mini project and demo it.
把前面的能力落到真实场景：日程助手、笔记整理、学习辅助、任务提醒等，选择一个场景完成迷你项目并现场展示。

By the end of the workshop, participants should have a working local setup, one connected model, one personalized Claw, and one practical demo they can keep iterating on.

课程结束时，每位参与者都应该拥有一个可运行的本地环境、一个已接入的大模型、一个个性化的 Claw，以及一个可以继续迭代的实用演示。
