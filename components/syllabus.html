Workshop Syllabus

课程安排

The following schedule outlines the planned sequence of sessions for the OpenClaw and ClawTwin Summer Workshop. It is split into confirmed dates and upcoming proposed topics.

以下是 OpenClaw 与 ClawTwin 夏季工坊的课程时间与大纲规划。包含已确定的课程安排以及后续计划中的探讨话题。

📅 Confirmed Schedule

📅 已确定课程安排

Session 1 第 1 课 June 15, 2026 (14:00 - 15:00) 2026年6月15日 (14:00 - 15:00)
OpenClaw Basic Setup & Environment Initialization OpenClaw 基础搭建与本地环境配置
Setup Step-by-step guidance on setting up the local environment, resolving dependency packages, cloning the OpenClaw repository, and starting your first local agent node.
配置 一步步带大家完成本地 Python 与依赖环境配置，拉取 OpenClaw 代码仓库，并成功运行起第一个本地智能体节点。
Session 2 第 2 课 June 22, 2026 (14:00 - 15:00) 2026年6月22日 (14:00 - 15:00)
LLM API Connection & Agent Persona Tuning 大模型 API 接入与智能体性格调优
Development Explaining how to hook up various Large Language Models (like DeepSeek, Kimi, Doubao, OpenAI) via API keys and customize the agent's behavior and tone of voice using system prompt design.
开发 讲解如何通过 API Key 为智能体接入不同的语言模型（如 DeepSeek, Kimi, 豆包等），并通过系统 Prompt 的设计来定制智能体的对话风格、语气和习惯。

💡 Planned Topics

💡 计划中的课程话题

Topic A 话题 A Late June (TBC) 6月下旬 (待定)
End-to-End Encrypted P2P Communication between Agents 智能体之间的端到端加密点对点通信
Security An overview of the agent-comm SDK, introducing secure key exchanges (X25519 ECDH), Double Ratchet protocol for forward secrecy, and routing mechanisms through the agent-comm-platform.
安全 剖析 agent-comm SDK 的核心原理，介绍如何利用双棘轮协议建立加密安全通道，以及如何通过中继节点实现 NAT 穿透和点对点消息传递。
Topic B 话题 B Early July (TBC) 7月上旬 (待定)
Human-in-the-Loop (HITL) Workflow & Approval System 人类介入（HITL）工作流与安全审批机制
HITL Deploying the agent-collaboration-web dashboard. How to set up an approval queue to review sensitive actions proposed by agents (e.g., sending calendars, transferring tokens, triggering actions) before they execute.
人类介入 结合 Web 端的集成部署，演示如何实现“人类介入（HITL）”队列。让智能体在执行敏感动作（如行程透露、代币转移、指令下发）前必须在网页端取得用户的授权。
