Workshop Syllabus

课程安排

This syllabus is designed as a zero-to-one workshop path for beginners. It starts with setup and model basics, then moves toward customization, agent patterns, and advanced network collaboration.

这门工坊面向零基础参与者设计，从环境搭建和大模型基础出发，逐步走向定制化、Agent 设计模式与去中心化网络协同。

Training, Fine-Tuning, and Iterating Custom Agent Models 训练、微调、迭代用于 Agent 的定制模型

针对工具调用、规划与任务执行等特定场景，对轻量级开源大模型进行本地微调、训练与评估的方法与平台实践。
Topic 9 话题 9 Speaker Pending 讲师待定
Cryptographic Applications in AI Agent Security 密码学在 Agent 当中的应用
How decentralized identity keys, zero-knowledge proofs, and secure tunnels secure multi-agent communication networks.
探索如何使用去中心化身份（DID）、非对称加密、双棘轮前向安全密钥协商等密码学手段，保障智能体协同网络中的隐私与数据安全。
Topic 10 话题 10 Speaker Pending 讲师待定
Analyzing Human-Agent Interactions (HAI) 怎么分析用户与 Agent 的交互
Quantitative and qualitative methodologies to study user behavior, interface expectations, trust building, and cognitive load during human-agent collaboration.
解析人机交互（HCI）方法在智能体领域的应用：如何定量/定性分析人类与智能体协作过程中的信任感、认知负荷及交互习惯。

By the end of the workshop series, participants should have a working local deployment, a customized agent, and a deep understanding of multi-agent communication networks.

系列课程结束时，每位参与者都将拥有一套可运行的本地智能体环境、一个专属定制的助理分身，并对多智能体通信网络生态有深刻理解。
