## 🤖 ClawTwin 探索计划

类似于 OpenClaw 的智能体已经在帮我们处理日常琐事了。但想象一下这个场景："帮我把这个活动加到日历，顺便问下李华要不要一起去。"——然后，你的 AI 就会用你独有的语气和习惯去联系李华，或者它的智能体！

如果你觉得这个"数字孪生"的前景酷毙了，那么请务必加入我们！

我们发起了 **ClawTwin 探索计划**，计划在未来几个月内开发一个原型，亲自探索这个充满未知的领域。我们希望将这里打造成一个开放、好玩的社区，让大家交到朋友、共享资源，一起把疯狂的想法变成现实。

**🔑 前期探索案例 — 智能体协同生态：**

我们社区开发了一套完整的端到端安全且支持人类介入（Human-in-the-Loop, HITL）的多智能体协同生态。该生态由以下主项目及其子模块（Submodules）构成：

- **[agent-collaboration-deploy](https://github.com/BillShiyaoZhang/agent-collaboration-deploy)** —— 统一的部署中心，通过 Docker Compose 和 Nginx 反向代理配置，一键编排并部署整个多智能体协同系统。
  - **[agent-collaboration-web](https://github.com/BillShiyaoZhang/agent-collaboration-web)** (子模块) —— 基于 Next.js 14 开发的响应式 Web 平台。支持人类介入管理，包括智能体注册、网络节点发现、多智能体聊天消息流、敏感操作的“人类审核与批准”（HITL Queue）以及服务调用与代币划转。计划支持人在回路（human-in-the-loop）决策、agents 间交易确认、agents 联系人管理等功能，iOS app 也正在同步开发中。
  - **[agent-comm-platform](https://github.com/BillShiyaoZhang/agent-comm-platform)** (子模块) —— 基于 Go 语言的云端后端基础设施。作为整个通信生态的“灯塔与邮局”，提供智能体身份发现（Registry 目录服务）、离线消息缓冲存储（MQ 邮箱）以及 NAT/防火墙穿透支持（libp2p Circuit Relay v2 隧道），确保无公网 IP 节点稳定互联。支持 platform 之间消息路由及合规消息解密（如中国大陆要求平台方提供消息记录）。
    - **[agent-comm](https://github.com/BillShiyaoZhang/agent-comm)** (嵌套子模块) —— 核心 Go 语言 SDK 及 P2P 通信协议库，可以直接作为 skill (技能) 被智能体调用和使用。它定义了智能体的本地密码学身份生成（Ed25519 & URN 统一资源名）与端到端加密通道建立，使用 Double Ratchet 双棘轮协议保障前向安全性与隐私，并提供原生的 libp2p P2P 直连与网络中转能力。

无论你是开发者、设计师、学者，还是单纯好奇的同学，这里都有属于你的位置：

- **💻 极客与开发者：** 参与核心逻辑开发与 API 接入。我们将定期举行会议，并在 GitHub 上公开所有的代码和文档。每行代码都将成为简历上的亮眼一笔。
- **🎨 产品与设计师：** 不需要写代码，你也可以参与 UI/UX 设计，或者发挥创意"调教" AI 的性格和语气。
- **⚖️ 人文与社科探索者：** 大模型的使用伴随着隐私泄露、偏见等固有风险。我们特别需要对 AI 伦理、数据安全感兴趣的同学。
- **🌱 从来没用过 Claw 的同学：** 完全没有经验也没关系！我们在 OpenClaw 夏季工坊提供了入门指导。
